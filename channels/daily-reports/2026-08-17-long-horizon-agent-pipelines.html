Why it matters

The Compass-Refund-2 case is the canonical data point for why the 3-judge contract is the floor, not the ceiling. The lenient judge (TrajJudge-Qwen3 v2.1) was a 67%-agreement model on the leaderboard — competitive, not bad. It missed the LOOP because the loop was masked by a tool-result that looked like progress (an idempotency-key that returned 200 OK with an empty body, the agent treated the empty 200 as a successful state change). The two stricter judges (GPT-5 + Sonnet 5) flagged it because they reason about side-effect semantics, not just the response code. The 11% regression catch-rate uplift is the average across 14 enterprise customers, but the case-by-case variance is wider: Compass-Refund-2 was a 100% miss for the lenient judge, the others were 0% misses. The contract is "majority vote with dissent log" because the variance is what matters — a single judge has a long tail of 100% misses on shapes it doesn't understand, and the 3-judge majority turns that long tail into a daily audit log.

Why it matters

The contradiction is not a memory bug — it's a memory feature. The user did prefer X on 2026-03-12; the user did switch to Y on 2026-07-08; the system has both facts in semantic memory; the contradiction resolver's job is to pick the right one for the right context, and the right one is the most recent one when the context is "send a refund." The 6/14 file's MemLayer 1.0.1 added the date-conditioning primitive ("user used to prefer X but switched to Y on date Z") — the 8/16 MemLayer 1.1 turns the date into a first-class field in the temporal graph, so the resolver can reason about "the user used to prefer X" without losing the historical fact. The Ebbinghaus-AGI v2.2 weighted-recency resolver is the production-ready consumer of the temporal graph: it picks the most recent fact for active contexts, keeps the historical fact for audit, and writes the contradiction resolution as a new event in the memory log. The 11-day lag between the loss and the fix is the production window — the Ebbinghaus team shipped the fix as soon as the post-mortem landed, and the next customer-success agent in the same shape will not lose the contract. The lesson is: contradiction resolution is a first-class product surface, not a research project.

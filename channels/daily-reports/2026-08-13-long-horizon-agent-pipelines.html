Tab 01 · End-to-End Agent Evaluation & Trajectory Benchmarking

Final-answer scoring marks a failing agent green. The answer was right. The path was wrong — 20 steps, two policy violations, an exfiltration. Trajectory eval closes that gap. The day a closed-source judge and an open-weights judge disagree on the same trajectory is the day you need three judges, not one.

Δ since 8/12 sweep: TrajJudge-Qwen3 v2 (released 8/12 23:00 CEST, 64% agreement on the TrajJudge-1k split, up from 48% on v1), ProcessBench v2 (the first benchmark to score recovery-from-failed-tool-call as a primary axis), LangSmith agentevals v0.7 (sub-agent call traversal in trajectory diff — finally), and the Anthropic Sonnet 5 mid-loop guardrail hooks that let you write trajectory-aware evals at the model layer. The trajectory-eval stack is no longer a side project; it's a contract.

Why it matters

A correct answer reached in 20 steps with two policy-violating intermediate calls is a failing trajectory. Production agents need four layers: unit, trajectory, outcome, online. Anything less accumulates technical debt in the form of undetected regressions. The Fortune 100 cart-loop post-mortem (released overnight) is the same shape as Klarna: the unit-test on the cart API was green for 11 days while the agent silently re-entered a recovery branch on a malformed but recoverable edge case — final answer was "added to cart," but 14% of sessions were doing it 8-12 times.

Tab 02 · Structured, Long-Term Memory with Automatic Consolidation

A context window is short-term and re-paid every turn. Memory is persistent, has its own storage tier, evolution rules, and a forgetting policy. The two are complements, not substitutes. The 4-tier split (working / episodic / semantic / procedural) is now the consensus pattern.

Δ since 8/12 sweep: MemLayer 1.0 GA (8/12 evening, the first open-weights memory layer with built-in contradiction resolution), Letta Episodic Mode (8/12, time-windowed episode memory with Ebbinghaus decay), and the Ebbinghaus-AGI v2 paper (arXiv:2608.04219) which formalizes the decay function across 14 note types. The 4-tier memory split (working → episodic → semantic → procedural) is now the consensus, not the frontier.

Why it matters

Vector RAG is a search index, not memory. Real memory needs: a working tier (the active context), an episodic tier (what happened, when, with whom), a semantic tier (what we know about the world), and a procedural tier (how to do things). Each tier has its own schema, retrieval path, and forgetting policy. A production agent without all four is a chatbot that re-learns your name every Monday. The Mem0 + Zep pattern (8/11) was the start; the 4-tier split is the landing.

Tab 04 · Tool Integration & Dynamic API Orchestration
